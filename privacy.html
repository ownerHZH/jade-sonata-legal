Privacy Policy

Jade Sonata: Mahjong Piano
HarmonyOS: 重庆侠猫科技有限公司
Android / iOS / Web: Luthfi Studio
Effective date: 2026-10-07

This policy explains information handling for Jade Sonata: Mahjong Piano. The HarmonyOS edition is provided by 重庆侠猫科技有限公司. Luthfi Studio is the existing publisher name for the Android, iOS and Web editions. References to the developer below mean the provider of the edition you use.

Information kept on your device

The installed game stores progress, settings, mistakes, hints, retries, key-press timing, performance takes and optional adaptive-difficulty summaries in app-private storage. These records support saving, replay, scoring and adjusting future levels. Performances contain game events, not microphone recordings.

Game records and platform sign-in

Full saves and performance events stay on the device. Recent gameplay summaries are transmitted automatically for personalized difficulty, as described below. The Android and iOS versions do not require a game account. The HarmonyOS version uses Huawei Game Service Kit for Huawei ID sign-in, identity verification and play-eligibility checks, which require a network connection. The native integration temporarily holds the returned game player identifier and eligibility information in memory; it does not send these identifiers to the Web game, save them in the game database or send them to a developer server. Huawei processes service information under the Game Services statement it presents. There are no ads, third-party analytics SDKs or cloud-save synchronization. StarRouter difficulty services provides automatic difficulty decisions. Game artwork, level data, scores, piano samples and these legal documents are packaged locally.

Permissions

Android declares Internet access for automatic difficulty decisions; HarmonyOS declares Internet access for those decisions and Huawei game services. iOS and Web use HTTPS networking without requesting a separate Internet permission. Gameplay does not request microphone, camera, location, contacts, phone, SMS or broad media/storage access. A backup is written only to a location you select in the system file panel.

Automatic difficulty decisions

When there is enough play history and a new level can be prepared, the game automatically sends a summary of up to 12 recent attempts to https://starrouter.io/api/alpha/decisions using HTTPS. The summary contains the next level number, play mode, current/local difficulty, sample confidence, attempt and decision counts, accuracy, hints, median decision time, hesitation count, clear/retry/assistance rates, clear/failure streaks, distinct cleared levels and the last outcome. It contains no name, email, device or advertising ID, Huawei player identifier, raw key events, performance recording, calendar date or full save. StarRouter receives ordinary request metadata, including the IP address, and processes requests with its configured inference providers. This information is used to select a suitable next challenge, not advertising or cross-app tracking. Provider infrastructure may process data outside your country.

Remote processing and retention

This build does not maintain a developer analytics database or upload local retention measurements. StarRouter and its configured inference providers handle network and service logs under their service practices; we do not promise zero logging or an unverified deletion period. Resetting local learning does not delete previously transmitted requests or provider logs. Contact us for information about processing, retention or a deletion request; we will assess the request with the relevant provider.

Exports you choose

You can explicitly export a backup using the system save or share panel. The destination you select receives that file and handles it under its own policies. We do not automatically upload backups. Exported copies outside the app remain under your control and must be deleted separately.

Retention and your choices

Local records remain until you clear app data or uninstall the game. Progress belongs to this device and is not a Huawei cloud save; switching Huawei accounts does not automatically erase or migrate that local progress. You can reset local learning without deleting earned progress. Automatic online personalization has no in-game off switch. To stop future requests, stop using the game. Network failures fall back to local rules and do not block the board. Android automatic cloud backup is disabled for this app. Keep your own exported copy if you need a backup; clearing app data can permanently remove local records.

Support correspondence

If you email our support address, we receive the address and information you choose to send and use them to respond and resolve the request. We retain correspondence only as needed for support and applicable obligations. Do not send unnecessary sensitive information. Contact us if you want to ask about or request deletion of information you sent us.

Website and external links

Opening the public website or an external link requires an Internet connection and sends ordinary web-request information, such as an IP address and browser information, to the receiving service and hosting providers. The game website uses OpenAI Sites, and these public legal pages use GitHub Pages. The hosting services handle requests under their own policies. The Web game keeps full saves in your browser; it sends the limited summaries described above for difficulty decisions. Clearing browser storage can remove those saves. Website traffic is separate from native Huawei sign-in and compliance checks. Android/iOS gameplay can continue using local rules when offline; the HarmonyOS game requires access to Huawei services for sign-in and eligibility verification.

Security and children

The installed games use app-private storage and expose exported files only through user-initiated saving or sharing. No method guarantees protection from device loss or unauthorized access to an unlocked device. We do not ask players to type their age or identity-document number into our game. The HarmonyOS version delegates identity and minor-protection checks to Huawei Game Services and does not manufacture a real-name or adult status. A parent or guardian can contact us about information a child has sent through support.

Changes and contact

We will reflect changes in this policy and its effective date. For privacy questions or requests, contact the provider of your edition at the email address below.

隐私政策

Jade Sonata: Mahjong Piano
HarmonyOS: 重庆侠猫科技有限公司
Android / iOS / Web: Luthfi Studio
生效日期: 2026-10-07

本政策说明《琴雀：麻将钢琴》（Jade Sonata: Mahjong Piano）的信息处理方式。HarmonyOS 版本由重庆侠猫科技有限公司提供；Android、iOS 和 Web 版本沿用 Luthfi Studio 作为发布者名称。下文中的开发者指你使用版本的提供方。

保存在设备中的信息

游戏在应用私有存储中保存进度、设置、误触、提示、重试、按键时序、演奏记录及可选的难度适应摘要，用于存档、回放、评分与调整后续关卡。演奏记录是游戏操作事件，不是麦克风录音。

游戏记录与平台登录

完整存档与演奏事件保留在设备中。近期游戏摘要会按下文说明自动发送，用于个性化难度判断。Android 和 iOS 版本不要求游戏账号；HarmonyOS 版本接入华为游戏服务，用于华为账号登录、实名及游玩资格核验，这些服务需要联网。原生接入仅在内存中暂存返回的游戏玩家标识和资格信息，不传给 Web 游戏、不写入游戏数据库，也不发送给开发者服务器。华为依据其展示的游戏服务声明处理服务信息。本游戏不含广告、第三方分析 SDK 或云存档同步；StarRouter 难度评估服务提供自动难度判断。画面、关卡、乐谱、钢琴采样及这些法律文档仍随应用安装。

权限

Android 为自动难度判断声明网络权限；HarmonyOS 为该判断及华为游戏服务声明网络权限。iOS 和 Web 使用 HTTPS 联网，无需单独申请网络运行时权限。游戏玩法不要求麦克风、相机、定位、通讯录、电话、短信或广泛的媒体与存储访问。备份仅写入你在系统文件面板中选择的目标位置。

自动关卡难度判断

在游玩样本充足且可以准备新关时，游戏通过 HTTPS 自动向 https://starrouter.io/api/alpha/decisions 发送最近最多 12 次尝试的汇总。字段包括下一关编号、演奏方式、当前与本地建议难度、样本可信度、尝试与决策次数、准确率、提示数、决策用时中位数、犹豫次数、通关/重试/辅助比例、连续通关/失败次数、不同已通关关卡数及最近结果。不包含姓名、邮箱、设备或广告标识、华为玩家标识、逐次按键、演奏记录、日期或完整存档。StarRouter 会接收 IP 地址等正常网络请求信息，并通过其配置的推理服务商处理请求。用途是选择合适的后续挑战，不用于广告或跨应用追踪。服务基础设施可能位于你所在国家或地区之外。

远程处理与保存

此构建不建立开发者分析数据库，也不上传本机留存测量数据。StarRouter 及其配置的推理服务商按其服务实践处理网络及服务日志；我们不承诺零日志或未经核实的删除期限。重置本机学习记录不会删除已经发出的请求或服务商日志。如需了解处理方式、保存期限或申请删除，请联系我们，我们会与相关服务商核实处理。

由你选择的导出

你可以主动通过系统保存或分享面板导出备份。你选择的接收方会收到该文件，并按其自身政策处理。我们不会自动上传备份。应用外的导出副本由你管理，需要单独删除。

保存期限与选择

本机记录保留至你清除应用数据或卸载游戏。进度属于此设备，不是华为账号云存档；切换华为账号不会自动删除或迁移这些本机进度。你可以重置本机学习记录，而不删除已获得的进度。自动联网个性化没有游戏内关闭开关；停止使用游戏可停止后续请求。网络失败时使用本地规则，不阻断关卡。本应用已禁用安卓自动云备份。需要备份时请保留自己的导出副本，清除数据可能永久移除本机记录。

支持邮件

当你向支持邮箱发送邮件时，我们会收到你的邮箱地址和你主动提供的信息，并用于回复及处理请求。我们仅在支持处理及适用义务所需期间保留往来邮件。请勿发送不必要的敏感信息。你可以联系我们，查询或申请删除曾发送的信息。

网站与外部链接

打开公开网站或外部链接需要联网，会向接收服务及托管服务发送正常的网页请求信息，例如 IP 地址及浏览器信息。游戏网站使用 OpenAI Sites，公开法律文档使用 GitHub Pages 托管；相关服务按各自政策处理请求。Web 游戏将完整存档保存在浏览器中，仅发送上文列出的有限摘要用于难度判断；清除浏览器存储可能移除记录。网站请求与原生华为登录及合规核验相互独立。Android/iOS 在离线时仍可按本地规则继续玩法；HarmonyOS 游戏的登录及游玩资格核验需要访问华为服务。

安全与儿童

安装版本使用应用私有存储，仅在用户主动保存或分享时向接收方提供导出文件。任何方式都无法保证避免设备丢失或他人访问未锁定设备的风险。我们不要求玩家在游戏内填写年龄或身份证件号码；HarmonyOS 版本由华为游戏服务执行实名与未成年人保护校验，本游戏不会自行认定实名或成年人状态。家长或监护人可就儿童通过支持渠道发送的信息联系我们。
