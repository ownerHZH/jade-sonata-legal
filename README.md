The homepage introduces actual gameplay and original artwork. It does not claim that unreleased store or mini-game editions are available. Legal document content and existing URLs are preserved.

## Publishing

GitHub Pages publishes the root of `main`. Plain HTML and CSS; no build step, external fonts, analytics, or client-side JavaScript. To preview: `python3 -m http.server 4178` and visit http://localhost:4178/.

## Assets

- `assets/garden.webp`: existing original AI-generated garden artwork from the Jade Sonata project (`dist/assets/garden-story.webp`).
- `assets/gameplay.jpg`: unmodified actual English Web gameplay captured 2026-10-04 (`mobile/store/screenshots/web-preview/01-web-gameplay.jpg`), not a native mini-game screenshot.
- `assets/favicon.svg`: existing project favicon.

The public repository contains presentation assets and legal pages only, not the private game source or signing credentials. Public availability does not grant a redistribution license for game artwork.
